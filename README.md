# Leaffliction

Image classification by disease recognition on plant leaves (Apple & Grape).

## Project Structure

```
scripts/
  Distribution.py    Part 1: Dataset analysis (pie/bar charts + augmented verification)
  Augmentation.py    Part 2: Balance dataset with 6 augmentation techniques
  Transformation.py  Part 3: 6 PlantCV image transformations
  Train.py           Part 4: CNN (ResNet50) training + evaluation
  Predict.py         Part 4: Classify a leaf image with trained model
notebooks/
  01_part.ipynb       Part 1: Distribution — dataset analysis (demo)
  02_part.ipynb       Part 2: Augmentation — balance dataset (demo)
  03_part.ipynb       Part 3: Transformation — 6 PlantCV transforms (demo)
  04_part.ipynb       Part 4: Train — CNN training + evaluation (demo)
  05_predict.ipynb    Part 4: Predict — classify a leaf image (demo)
src/
  data.py             Dataset paths, class definitions, and load_datasets (train/val/test splits)
  augmentation.py     6 augmentation transforms (Flip, Rotate, Skew, Shear, Crop, Distortion)
  features.py         Hand-crafted feature extraction (PlantCV)
  model/
    train.py          ResNet50 CNN training pipeline
    evaluate.py       Model evaluation (accuracy, F1, confusion matrix)
    callbacks.py      Custom Keras callbacks (per-class F1 early stopping)
model/                Saved model (model.keras + class_names.txt)
augmented_directory/  Balanced dataset (generated by Augmentation.py)
test/
  Unit_test1/         Apple test images
  Unit_test2/         Grape test images
signature.txt         SHA1 hash of model.zip
```

## Evaluation Flow

1. **Part 1** — Run `Distribution.py`: shows pie/bar charts for imbalanced dataset
2. **Part 2** — Run `Augmentation.py`: generates 6 augmentations, balances into `augmented_directory/`
3. **Part 1 (verify)** — Run `Distribution.py` again: re-runs Distribution on `augmented_directory/` to confirm equal pie slices
4. **Part 3** — Run `Transformation.py`: shows 6 PlantCV transformations (blur, mask, ROI, analyze, pseudolandmarks, color histogram)
5. **Part 4 (train)** — Run `Train.py`: trains ResNet50, evaluates >90% accuracy, saves `model.zip`. A test split is held out by `load_datasets` (returned as `test_ds`) and never seen during training
6. **Part 4 (evaluate)** — Evaluate on the held-out test split (unseen from training) alongside the `test/Unit_test1` and `test/Unit_test2` images
7. **Part 4 (predict)** — Run `Predict.py`: loads model, shows original + transformed image + disease classification

## Requirements

- Python >= 3.11
- Dependencies: tensorflow, keras, albumentations, plantcv, opencv-python, matplotlib, scikit-learn, pillow

## Usage

```bash
# Install dependencies
pip install -e .

# Part 1 — Distribution analysis
python scripts/Distribution.py

# Part 2 — Balance dataset via augmentation
python scripts/Augmentation.py

# Part 2 — Augment a single image
python scripts/Augmentation.py path/to/image.jpg

# Part 3 — PlantCV transformations (single image)
python scripts/Transformation.py path/to/image.jpg

# Part 3 — PlantCV transformations (batch directory)
python scripts/Transformation.py -src data/leaves/images/Apple_healthy -dst transformed_output

# Part 4 — Train CNN
python scripts/Train.py

# Part 4 — Predict disease on a leaf
python scripts/Predict.py path/to/leaf.jpg
```
